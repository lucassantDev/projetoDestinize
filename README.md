## Sobre o projeto

Este foi meu primeiro projeto desenvolvido com HTML e CSS, criado em 2024. Agora decidi revisitar o projeto e refatorar sua estrutura utilizando Vue.js e Tailwind CSS.

## Tecnologias e bibliotecas

- HTML5
- CSS3
- Vue.js 3
- Vite
- Tailwind CSS 4, utilizado via CDN
- Lucide Vue, para os ícones da interface
- @vitejs/plugin-vue, para integração do Vue com o Vite

## Como executar o projeto

### Pré-requisitos

É necessário ter o Node.js e o npm instalados.

### Instalação

Clone o repositório e acesse a pasta do projeto:

```bash
git clone <URL_DO_REPOSITORIO>
cd projetoDestinize
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse a URL exibida no terminal, normalmente `http://localhost:5173`.

## Build para produção

Para gerar os arquivos de produção:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
